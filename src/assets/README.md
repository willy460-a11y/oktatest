# Assets Folder

Plaats hier je productie assets:

## Logo
- **trescal-logo.png** - Het Trescal logo (aanbevolen: PNG, transparante achtergrond)
- **trescal-logo.svg** - Of gebruik SVG voor schaalbare kwaliteit

## Aanbevolen formaten:
- **Logo hoogte:** 32-40px (h-8 in de app = 32px)
- **Bestandsformaat:** PNG met transparantie of SVG
- **Kleur:** Trescal blauw (#0077C8) of wit voor dark mode

## Gebruik in code:
```tsx
import trescalLogo from './assets/trescal-logo.png';
// of
import TrescalLogo from './assets/trescal-logo.svg';
```
