
  # Website Redesign Repository (Front)

  This is a code bundle for Website Redesign Repository (Copy). The original project is available at https://www.figma.com/design/LPHhL5JZrrSxxP5S4SI8QZ/Website-Redesign-Repository--Copy-.

  ## Running the code

  Backend dependencies (Flask + Okta):
  
  - Install Python packages: `pip install -r backend/requirements.txt`

 Dit zijn:
 "flask"
 "flask-cors"
 "authlib"
  
  ### Quick start

  For a quick start just run `start_docflow.py`

  #### Backups 
  
  onder map backups staan backups. Om weer een backup te gebruiken stop docflow en veranderd de backup die je wilt gebruiken naar `state` en verplaats het onder de main map. De state json onder de backend map is nog spaghetti code..
  
  
  ##### Node.js 
  
  Vanwege de complexiteit van het opzetten van Node.js doet de `start_docflow.py` het opzetten van de Node.js zelf uit. Download de nieuwste versie bij https://nodejs.org/en en download de ZIP. Pak het uit en pas het aan in `start_docflow.py` de locatie van de map. Lijn 40* in `start_docflow.py`.

  Is nog in ontwikkeling. bedoeling is om de files te kunnen openen bij het gebruik van de browser.
